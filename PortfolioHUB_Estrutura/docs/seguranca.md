# Políticas de Segurança e Perfis de Acesso

## Perfis de Acesso
- **Administrador:** Gerencia configurações, colaboradores e regras do repositório.
- **Desenvolvedor/Colaborador:** Cria branches, envia alterações e abre Pull Requests.
- **Visualizador:** Consulta o projeto e a documentação sem modificar o código.

## Boas Práticas
- Princípio do menor privilégio.
- Autenticação em Dois Fatores (2FA) ativada.
- Proteção da branch principal via Pull Request.
- **Uso estrito de Variáveis de Ambiente:** Nenhuma chave de API, senha ou token no código.
